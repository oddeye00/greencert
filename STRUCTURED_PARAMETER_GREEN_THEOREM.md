# Structured parameter-only Green closure

Status: post-v1.0.1 theorem development. This result does not alter any frozen
or prospective count in the released paper.

## Setting

Let a state map have a linear state component and parameter-only nonlinearity,

\[
G(c_j+u)-G(c_j)-DG(c_j)u=B_jR_j(Pu),
\]

where (P) projects state onto parameters and (B_j) injects the nonlinear
forcing back into state. Let (K_H) be the anchor-fixed causal Green operator
of (DG(c_j)), and define the structured parameter Green operator

\[
T_H=P K_H B.
\]

For scaled momentum,

\[
G(\theta,w)=(\theta-r,r),\qquad
r=\mu w+\eta\nabla F(\theta),
\]

the factorization is exact with

\[
P(\delta\theta,\delta w)=\delta\theta,
\qquad Bq=(-\eta q,\eta q),
\]

and

\[
R_j(e)=\nabla F(\theta_j+e)-\nabla F(\theta_j)-H_je.
\]

Thus neither the nonlinear remainder nor a neural-output event depends on an
arbitrary momentum perturbation.

## Theorem (parameter-only corrected-path closure)

Let (b_0=x_a,b_1,\ldots,b_H) be any reference path, let

\[
s_j=G(b_j)-b_{j+1},\qquad J_j=DG(b_j),
\]

and let (K_H) be generated by (J_0,\ldots,J_{H-1}). Suppose the exact
remainder factorization above holds. Assume that, on the declared parameter
domains,

\[
\|R_j(u)\|\le\frac{L_j}{2}\|u\|^2.
\]

The usual (L_j)-Lipschitz Hessian condition implies this inequality by the
integral Taylor formula. Let (L=\max_jL_j) and

\[
\kappa_\theta\ge\|T_H\|,
\qquad Y_\theta\ge\|P K_Hs\|_2.
\]

If

\[
D_\theta=1-2\kappa_\theta L Y_\theta\ge0,
\qquad
E_\theta=\frac{2Y_\theta}{1+\sqrt{D_\theta}},
\]

and every parameter ball of radius (E_\theta) lies in its declared domain,
then the realized trajectory satisfies

\[
\left(\sum_{j=1}^{H}
\|P(x_{a+j}-b_j)\|^2\right)^{1/2}\le E_\theta.
\]

Consequently any event depending only on neural parameters can be transported
directly from this parameter tube; a full optimizer-state tube is unnecessary.

### Proof

Writing (e=x-b), causal substitution gives

\[
e=K_Hs+K_HB R(Pe).
\]

Hence (p=Pe) solves the closed parameter-sequence equation

\[
p=P K_Hs+T_HR(p).
\]

On the radius-(E) parameter ball, Taylor's theorem gives

\[
\|R(p)\|_2\le \frac{L}{2}\|p\|_2^2.
\]

Therefore the right-hand side maps the ball into itself whenever

\[
Y_\theta+\frac12\kappa_\theta L E^2\le E.
\]

Brouwer yields a parameter fixed point. Defining

\[
e=K_H\{s+B R(p)\}
\]

recovers a full-state solution whose parameter projection is (p). Causal
forward recurrence is unique, so this solution is the realized error. The
stable smaller root is the displayed (E_\theta).

## Exact dominance over the released full-state closure

For scaled momentum, (|P|=1) and (|B|=\sqrt2\eta). Therefore

\[
\|P K_HB\|\le\sqrt2\eta\|K_H\|,
\qquad
\|P K_Hs\|\le\|K_Hs\|.
\]

The parameter-only quadratic coefficient and response term are each no larger
than those in the full-state corrected-path theorem. With exact operator
quantities, its root is therefore never worse for a parameter-defined event
and is strictly better whenever either inequality is strict.

Randomized numerical upper bounds need not preserve samplewise dominance, so a
matched implementation must retain both routes and select only through a
predeclared, probability-accounted policy.

## Computational consequence

The matrix-free products for (T_H=P K_HB) use the same causal optimizer JVPs
as the full Green operator, but probe vectors and stored outputs have half the
dimension. More importantly, the restricted gain can satisfy direct-image or
low-power Gram closure before the full operator, avoiding transpose sweeps or
higher powers. This is an empirical question addressed by a separate
post-release audit; the theorem itself does not assume a speedup.

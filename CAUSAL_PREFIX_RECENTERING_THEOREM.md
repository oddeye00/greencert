# Causal prefix theorem for variationally recentered paths

## Proposition (prefix commutation)

Let `A_H(x_0)` be the length-`H` affine reference generated by a causal
one-step recurrence, and let `R_H` denote one anchor-fixed signed variational
recentring sweep on a reference prefix of length `H`.  For `h <= H`, let `P_h`
retain states `0,...,h`.  Whenever the numerical/domain guard does not truncate
either construction before `h`,

```text
P_h A_H(x_0) = A_h(x_0),
P_h R_H(c)   = R_h(P_h c).
```

Consequently, for any fixed number `S` of sweeps,

```text
P_h R_H^S A_H(x_0) = R_h^S A_h(x_0).                         (1)
```

### Proof

The affine recurrence at step `j+1` uses only its state at `j`, so its first
`h` transitions are independent of a later terminal horizon.  In one
variational sweep,

```text
d_0 = 0,
d_{j+1} = D G_j(c_j) d_j + G_j(c_j) - c_{j+1},
(R_H c)_j = c_j + d_j.
```

Thus `d_{j+1}` depends only on `(c_j,c_{j+1},d_j)`.  Induction on `j` proves
the second identity.  Induction on the sweep index gives (1).

## Streaming realization

At a fixed time step, sweep `k` needs only the preceding sweep's states at the
current and next times and its own current correction.  All `S` sweeps can
therefore be pipelined in one forward pass while retaining only the final path
and `O(S)` live state vectors.  This reduces intermediate centerline storage
from `O(S H n)` to `O(H n + S n)` without changing the path.

If a persistent predicted event is defined by `p` consecutive true states, the
stream may stop as soon as the first such run is observed.  Equation (1)
guarantees that this prefix is exactly the prefix that a longer construction
would have produced.  In a sealed-candidate certificate where the event offset
and horizon `h=offset+p-1` are already fixed, construction may start directly
with that horizon; no state after `h` enters any Green, derivative, or output
inequality.

This proposition changes computation and storage, not the certificate or its
probability budget.
